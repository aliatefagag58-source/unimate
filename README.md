# UniMate — تحديث تسجيل الدخول والمزامنة السحابية

## الملفات
استبدل ملفات المشروع الموجودة في جذر مستودع GitHub بهذه الملفات. لا تحذف المستودع.

## ما يقدمه التحديث
- تسجيل حساب بالبريد وكلمة المرور وتسجيل الدخول والخروج عبر Supabase Auth.
- حفظ المواد والمهام والحضور والغياب في قاعدة البيانات السحابية.
- رفع PDF والصور إلى مساحة تخزين خاصة بالحساب، وروابط فتح مؤقتة.
- واجهة عربية متجاوبة ومظهر ليلي.
- البيانات مقيدة بسياسات RLS الموجودة في مشروع Supabase.

## إعداد مطلوب قبل التشغيل
في لوحة Supabase افتح Authentication > URL Configuration:
- Site URL: https://aliatefagag58-source.github.io
- أضف Redirect URL: https://aliatefagag58-source.github.io/unimate/**

ومن Authentication > Providers > Email:
- لو تأكيد البريد الإلكتروني مفعّل، المستخدم يحتاج تأكيد البريد قبل أول تسجيل دخول.
- يمكن تركه مفعّلًا للأمان.

## حدود النسخة
- المساعد الذكي ما زال واجهة تجريبية، ولم يتم ربط نموذج AI.
- الترجمة الإنجليزية الكاملة لم تنفذ بعد.
- لا يوجد استيراد تلقائي للبيانات القديمة المحفوظة محليًا.
- لا تضع Service Role Key في ملفات الواجهة. المفتاح المنشور المستخدم هنا مخصص للواجهة مع RLS.

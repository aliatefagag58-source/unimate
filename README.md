# UniMate — النسخة الأولى

تطبيق ويب تقدمي (PWA) عربي لتنظيم الدراسة، مبني من الصفر كبداية قابلة للتطوير.

## تشغيل سريع
- افتح `index.html` في متصفح حديث لمعاينة الواجهة.
- لتجربة التثبيت والعمل دون اتصال، شغّل مجلد المشروع من خادم محلي أو استضافة HTTPS؛ Service Worker لا يعمل عادةً من `file://`.
- يمكن ضغط المجلد ورفعه على استضافة صفحات ثابتة تدعم HTTPS.

## الموجود في النسخة الحالية
- واجهة عربية RTL متجاوبة مع شاشات الهاتف والكمبيوتر.
- لوحة رئيسية وإحصائيات.
- إضافة مواد دراسية وحذفها.
- إرفاق ملفات PDF والصور وفتحها.
- قائمة مهام مع تاريخ واكتمال/حذف.
- تسجيل حضور وغياب لكل مادة وحساب النسبة.
- واجهة محادثة تجريبية للمساعد الذكي.
- مظهر ليلي وحفظ محلي للبيانات.

## حدود مهمة قبل الاستخدام الحقيقي
هذه نسخة أولية تعمل محليًا داخل المتصفح، وليست بعدُ نظامًا متعدد المستخدمين:
- لا يوجد تسجيل دخول أو مزامنة بين الأجهزة أو قاعدة بيانات سحابية.
- البيانات والملفات تحفظ في تخزين المتصفح؛ حذف بيانات المتصفح قد يحذفها.
- المساعد الذكي واجهة فقط. ربطه يتطلب Backend ومفتاح API محفوظ على الخادم، وليس داخل كود المتصفح.
- لا ترفع ملفات شخصية أو حساسة قبل إضافة المصادقة والتخزين الآمن والنسخ الاحتياطي.

## الخطوات التالية
1. Backend وقاعدة بيانات ومصادقة للمستخدمين.
2. تخزين ملفات خاص بكل حساب مع صلاحيات وصول.
3. ربط المساعد الذكي عبر خادم آمن.
4. ترجمة واجهة إنجليزية كاملة واختبارات وظيفية وأمنية.
